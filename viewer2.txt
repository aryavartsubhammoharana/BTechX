================================================================================
BTechX - Viewer 2 Architecture (Standalone Common Page PDF System)
File: viewer.html & assets/js/pdf-modal.js
Version: v15.2 (New Full-Page Responsive Architecture)
================================================================================

1. CORE PHILOSOPHY & OBJECTIVE:
   - Replace the cramped, isolated modal popup with a dedicated, unified 
     fullscreen reading experience hosted on a single common page: `viewer.html`.
   - Seamless navigation in the SAME browser tab without losing BTechX's dark
     glassmorphism aesthetic.
   - Preserves user history: Clicking "← Back" returns students directly to
     the exact originating page (e.g. syllabus.html or 1stYearSub/math1.html)
     and remembers scroll position via `window.history.back()`.

2. UNIFIED URL STRUCTURE:
   - Any PDF link on any subject or syllabus page navigates to:
     viewer.html?file={normalized_pdf_path}&title={document_title}
   - Example 1 (Syllabus):
     viewer.html?file=Data/Syllabus/1st Year/math_1.pdf&title=Mathematics%20I%20Syllabus
   - Example 2 (Notes):
     viewer.html?file=Data/Subjects/1st year/BEE/Unit - I/bee.1.1.pdf&title=DC%20Circuit%20Analysis
   - Example 3 (QNA):
     viewer.html?file=Data/Subjects/1st year/Math/M2/UNIT I/Unit-I Question Bank (1).pdf&title=Unit-I%20Question%20Bank

3. DUAL-DEVICE ADAPTIVE DESIGN:
   A. MOBILE EXPERIENCE (Lightweight, Distraction-Free):
      - Minimalist, thumb-friendly sticky topbar:
        * Left: Prominent "← Back" button to return instantly.
        * Center: Truncated document title.
        * Right: Direct "⬇ Download" action button to save PDF locally for
          stylus/touch annotation in native mobile apps (Adobe Acrobat, Drive, WPS).
      - Clutter-free full viewport height dedicated to the document canvas.
      - Zero heavy annotation scripts or desktop UI overhead on mobile.

   B. DESKTOP EXPERIENCE (Power-User Productivity):
      - Full-width Glassmorphic control bar:
        * Left: "← Back" button + BTechX branding pill.
        * Center: Full document title & subject breadcrumb.
        * Right: "Open in New Tab" popout, "Fullscreen (F11)" toggle, and
          monochrome glow "Download PDF" pill button.
      - Fullscreen high-performance PDF renderer inside hardware-accelerated iframe.

4. 404 & FALLBACK HANDLING:
   - If the requested PDF file does not exist, is marked "#", or fails network fetch:
     * Beautiful glassmorphic "Study Material In Progress" / "PDF Not Found" screen.
     * Helpful message informing students notes will be uploaded soon.
     * Big "← Return to Previous Page" button.

5. BENEFITS OVER VIEWER 1:
   - No modal clipping or nested scrollbar conflicts.
   - Clean, professional URL sharing (students can copy and share direct viewer links).
   - Consistent Black & White monochrome design system across the reading experience.
   - Highly maintainable: only 1 HTML file (`viewer.html`) handles all curriculum PDFs.
